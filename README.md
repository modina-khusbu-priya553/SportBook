#  SportNest - Sports Facility Booking Management System

SportNest is a modern sports facility booking platform where users can discover, explore, and book sports facilities easily.

## 🌐 Live Website
https://sport-nest-9w11.vercel.app/

## 🎯 Purpose
SportNest is designed to make sports facility booking simple and convenient. Users can explore different sports facilities, search and filter facilities, view facility details, make bookings, and manage their bookings.

Facility owners can also add, update, and delete their own sports facilities.

## ✨ Features

- 🏠 Modern and responsive homepage
- 🏟️ Featured sports facilities
- 🔎 Search facilities by name
- 🏷️ Filter facilities by sport type
- 📋 View detailed facility information
- 📅 Book facilities for specific dates and time slots
- 💰 Automatic total price calculation
- 📖 View personal bookings
- ❌ Cancel bookings
- ➕ Add new sports facilities
- ✏️ Update owned facilities
- 🗑️ Delete owned facilities
- 👤 Manage personal facilities
- ⏳ Loading states
- 🚫 Custom 404 page
- ⚠️ Custom error page
- 📱 Fully responsive design
